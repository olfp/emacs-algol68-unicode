# ALGOL 68 Unicode Publishing Language Mode for Emacs

Based on the idea:
https://gist.github.com/lassehp/00dd99f1ec8992e07a727f57d760930d

[Screenshot on XFCE Mousepad with pretty Algol68 code](https://private-user-images.githubusercontent.com/5690305/460351368-14b285cf-a12a-40ef-82b8-2c1b1fdeaf2b.png){:target="_blank"}

To include in your config add
```
(load (expand-file-name "algol68/unicode.el" user-emacs-directory))
```
to your .emacs or init.el.
